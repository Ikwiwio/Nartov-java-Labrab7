Скриншоты для отчёта нужно сделать после локального запуска (я не подменяю их синтетическими изображениями). Снимите 3–5 экранов браузера/Postman для:
1. GET http://localhost:8080/actuator/health
2. GET http://localhost:8080/actuator/info
3. GET http://localhost:8080/actuator/metrics
4. GET http://localhost:8080/actuator/beans
По желанию пятый: GET http://localhost:8080/actuator/metrics/jvm.memory.used
Вставьте фактические снимки в отмеченные места отчёта.
